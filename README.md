# Tidy Quest (trial)

A tidy-up game for Android tablets. A grown-up photographs the mess and records a voice note for each step ("Lego in the red box", "pants in the washing basket"). The child works through the steps as a game in their chosen style and earns family credits to spend in a reward shop the grown-up sets up.

## Styles
Army, Karate, Superhero, Pop Star, Space and Football. Each has its own ranks (Recruit to General, White Belt to Black Belt, and so on), credit name, sounds and look. The child picks their own.

## Getting the APK
Every push to `main` builds the app on GitHub. When the build finishes (about 5 minutes), the APK is on the repo's **Releases** page under **Tidy Quest trial build**, file `TidyQuest-trial.apk`. You can also run the build by hand from the **Actions** tab ("Build Tidy Quest APK" → Run workflow).

## Installing on a tester's tablet
1. Open the release link on the tablet and download `TidyQuest-trial.apk`.
2. Open the download. Android asks to allow installs from the browser or Files app: tap **Settings**, switch on **Allow from this source**, go back and tap **Install**.
3. If Play Protect warns about an unknown app, tap **More details → Install anyway**. That warning appears for any app not from the Play Store.
4. Open Tidy Quest, enter the child's name, choose a 4-digit grown-up PIN, and let the child pick a style.

Requires Android 8 or newer. Allow the camera and microphone when asked.

### Amazon Fire tablets (including Kids editions)
- Install and use Tidy Quest from the **parent's profile**. Sideloaded apps don't appear in Amazon Kids child profiles. The app's own PIN keeps the grown-up area locked.
- Before installing: **Settings → Security & Privacy → Apps from Unknown Sources**, and allow the browser (Silk) or Files app.

## How a trial family uses it
- **Grown-up:** tap the lock, enter the PIN, **New job** → photo of the mess → **Add a step** for each instruction (record voice, optional words) → set credits, optional Beat the clock timer, after photo, daily repeat → **Save**.
- **Child:** taps the job, presses the start button, listens to each step, ticks it off. Finishing sends it to the grown-up.
- **Grown-up:** **To check** tab → Approve (credits added) or Not done yet. Reward purchases also appear there to mark as given or refund.
- **Rewards** tab: edit the shop. Anything goes: pudding, screen time, pick the film, stay up later, pocket money.

## Trial limits
- Everything is stored on the tablet only. Uninstalling deletes it.
- One device: parent and child use the same tablet (the PIN keeps the grown-up area private).
- The APK is signed with a test key, so a later build may need the old one uninstalling first.
